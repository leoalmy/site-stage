## 🧠 Architecture Technique

Le site utilise une architecture SPA (Single Page Application) légère sans framework lourd.

### Système de Routage (`js/router.js`)
- Utilise le hash de l'URL (`#page`) pour déterminer le contenu à afficher.
- Charge dynamiquement le contenu HTML depuis le dossier `view/`.
- Charge dynamiquement le CSS spécifique à la page depuis le dossier `style/`.
- Gère la navigation active et l'état du menu.

### Chargement des Vues (`js/header_footer.js`)
- Utilise l'attribut `data-include` pour injecter des composants communs (header, footer).
- Gère le menu burger et les interactions mobiles.
